dplyr es el paquete que más uso en R, y estas son 5 funciones que me resuelven la vida todos los días. Si las dominas, tu análisis de datos va a otro nivel.

0. Los datos de ejemplo

Para que no tengas que buscar datos, trabajaremos con un registro simulado de doce negocios de las principales ciudades del país: Loja, Quito, Cuenca y Guayaquil. Las ventas y los costos están en dólares y se generaron al azar con set.seed(2026), así que los números no corresponden a ninguna empresa real.

library(dplyr)
library(knitr)

set.seed(2026)
df <- data.frame(
  id     = 1:12,
  ciudad = sample(c("Loja", "Quito", "Cuenca", "Guayaquil"), 12, replace = TRUE),
  ventas = round(rnorm(12, 5000, 1200)),  # ventas mensuales en USD
  coste  = round(rnorm(12, 3000, 600))    # costos operativos en USD
)

df |>
  head() |>
  kable(caption = "Primeras filas del registro simulado de negocios.")
Primeras filas del registro simulado de negocios.
id ciudad ventas coste
1 Loja 4118 2517
2 Loja 3776 3414
3 Loja 5136 2803
4 Quito 4431 2901
5 Loja 4510 2165

Fuente: elaboración propia con datos simulados. Ahora sí, veamos las funciones.

1. pull() — sacar una columna como vector

¿Necesitas una columna suelta para un gráfico, un if, o pasarla a otra función? pull() extrae la columna como vector sin recurrir al $:

df |>
  pull(ventas) |>
  max()   # vector directo: puedo aplicar cualquier función de base
[1] 6616

Con este dato podemos responder preguntas sencillas, por ejemplo: “¿cuál fue la venta máxima registrada en la muestra?” — justamente el valor que devuelve.

💡 Tip: pull() es ideal cuando el resultado tiene una sola columna, p. ej. tras un summarise(), y quieres ese valor en condicionales o en otra función.

2. slice_max() — el top-N de un grupo

Top de ventas, mejores resultados, mayores movimientos… slice_max() devuelve las filas con los valores más altos (y slice_min() los más bajos):

df |>
  slice_max(ventas, n = 3)
  id    ciudad ventas coste
1 10 Guayaquil   6616  3035
2 11      Loja   5740  3387
3 12    Cuenca   5261  4035
# El negocio con mayores ventas de CADA ciudad (argumento by):
df |>
  slice_max(ventas, n = 1, by = ciudad)
  id    ciudad ventas coste
1 11      Loja   5740  3387
2  4     Quito   4431  2901
3 12    Cuenca   5261  4035
4 10 Guayaquil   6616  3035

El primer resultado te da el ranking nacional; el segundo, el ranking local: cuál fue el negocio más fuerte en Loja, cuál en Quito, etc. Son preguntas muy comunes en informes de ventas por territorio.

3. across() — aplicar algo a varias columnas

¿Media de todas las columnas numéricas? ¿Redondear cinco columnas? across() dentro de summarise() o mutate() aplica una función a varias columnas a la vez:

df |>
  summarise(
    across(c(ventas, coste), mean)
  )
    ventas    coste
1 4593.167 3279.083
# Con .names controlamos el nombre de las nuevas columnas:
df |>
  summarise(
    across(c(ventas, coste), mean, .names = "media_{.col}")
  )
  media_ventas media_coste
1     4593.167    3279.083

Si no usaras across(), tendrías que escribir dos summarise() separados o un mutate() por cada columna. Con diez columnas, el ahorro de líneas es evidente.

El orden de las columnas importa más de lo que crees (sobre todo al exportar o mostrar tablas). relocate() mueve columnas sin más líneas:

5. case_when() — condiciones en cascada

El ifelse() anidado es feo y frágil. case_when() evalúa condiciones en orden y devuelve el primer resultado que cumple:

df |>
  mutate(desempeno = case_when(
    ventas >= 6000 ~ "Excelente",
    ventas >= 4500 ~ "Bueno",
    ventas >= 3500 ~ "Regular",
    TRUE           ~ "Crítico"
  )) |>
  select(id, ciudad, ventas, desempeno)
   id    ciudad ventas desempeno
1   1      Loja   4118   Regular
2   2      Loja   3776   Regular
3   3      Loja   5136     Bueno
4   4     Quito   4431   Regular
5   5      Loja   4510     Bueno
6   6    Cuenca   4123   Regular
7   7    Cuenca   4734     Bueno
8   8 Guayaquil   4729     Bueno
9   9 Guayaquil   1944   Crítico
10 10 Guayaquil   6616 Excelente
11 11      Loja   5740     Bueno
12 12    Cuenca   5261     Bueno

Interpretación: el código clasifica cada negocio según su nivel de ventas, de Excelente a Crítico. Con esta columna podrías, por ejemplo, contar cuántos negocios de cada ciudad necesitan atención:

df |>
  mutate(desempeno = case_when(
    ventas >= 6000 ~ "Excelente",
    ventas >= 4500 ~ "Bueno",
    ventas >= 3500 ~ "Regular",
    TRUE           ~ "Crítico"
  )) |>
  count(ciudad, desempeno) |>
  kable(caption = "Número de negocios simulados por ciudad y desempeño.")

Bono: reframe() para devolver varias filas por grupo

A diferencia de summarise(), reframe() permite devolver más de una fila por grupo (perfecto para rangos, cuantiles o top-N):

df |>
  reframe(
    cuantil = c(0.25, 0.75),
    valor   = quantile(ventas, c(0.25, 0.75))
  )
  cuantil   valor
1    0.25 4121.75
2    0.75 5167.25

En este caso obtenemos, para el total de la muestra, los cuartiles 25 y 75 de las ventas: una manera rápida de describir cómo se reparte el dinero entre los negocios simulados.

Resumen

Función ¿Para qué?
pull() Extraer una columna como vector
slice_max() / slice_min() Top-N (global o por grupo)
across() Aplicar funciones a muchas columnas
relocate() Reordenar columnas fácil
case_when() Condiciones múltiples y limpias
reframe() Varias filas de resultado por grupo

Memoriza estas funciones y tendrás el 80 % del análisis de datos diario resuelto. Los datos de este post son simulados, pero el procedimiento es exactamente el mismo que usarías con un registro real de tu trabajo o tus clases. 🚀
